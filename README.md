# 🌻 Fibonacci a la natura — Qüestionari d'avaluació

Aplicació web interactiva dissenyada per a l'avaluació de l'alumnat de **Cicle Superior de Primària (5è i 6è)** sobre la proposta didàctica **"Fibonacci a la natura"** (emmarcada dins el programa PCMAT / Código Escuela 4.0).

El qüestionari consta de **20 preguntes** dividides en quatre blocs temàtics amb retroacció immediata, il·lustracions vectorials explicatives i un informe final detallat.

---

## ✨ Característiques principals

* **20 preguntes estructurades en 4 blocs temàtics:**
  1. 🔢 **Bloc 1: Successions numèriques** (qui era Fibonacci, regla de formació i piràmides numèriques).
  2. ✨ **Bloc 2: Regularitats i prediccions** (sumes acumulades, múltiples de 2 i combinatòria d'esglaons).
  3. 🐚 **Bloc 3: De la geometria a la natura** (construcció de l'espiral de Fibonacci, patrons en gira-sols, pinyes, cargols i l'angle d'or de $137,5^\circ$).
  4. 🐝 **Bloc 4: Les abelles i la programació del robot** (camins al rusc hexagonal i cicle de programació: *Programa, Prova, Observa, Ajusta, Torna-hi*).
* **Suport visual dinàmic (SVG):** Esquemes vectorials integrats a les preguntes clau (piràmide de 4 pisos, espiral sobre quadrats, angle d'or i rusc hexagonal).
* **Retroacció formativa immediata:** Cada resposta ofereix una explicació clara i adaptada a l'edat de l'alumnat tant si s'encerta com si es falla.
* **Informe final de resultats:** Puntuació global, percentatge, missatge motivador personalitzat, gràfic de rendiment per blocs i desplegable de revisió de totes les preguntes.
* **Sense dependències d'instal·lació:** Tot el codi (HTML, CSS i JavaScript) està contingut en un únic fitxer autoexecutable.

---

## 🚀 Com utilitzar l'aplicació

### Opció 1: Execució local (a l'aula o ordinador)
1. Descarrega el fitxer `.html` del repositori (per exemple, `fibonacci_natura_quiz.html`).
2. Fes doble clic sobre el fitxer per obrir-lo amb qualsevol navegador web modern (Chrome, Firefox, Edge, Safari).
3. No requereix connexió a internet per funcionar (excepte per carregar la tipografia i els estils de Tailwind CSS des de la CDN).

### Opció 2: Publicació amb GitHub Pages
Per compartir l'enllaç directament amb l'alumnat:
1. Puja el fitxer al teu repositori de GitHub i reanomena'l com a `index.html`.
2. Ves a **Settings** > **Pages** dins del repositori.
3. A l'apartat *Branch*, selecciona `main` (o `master`) i la carpeta `/ (root)`, i fes clic a **Save**.
4. En uns segons tindràs una URL pública llesta per compartir a Google Classroom, Moodle o a la pissarra digital.

---

## 🛠️ Tecnologies utilitzades

* **HTML5** semàntic i accessible.
* **Tailwind CSS** (via CDN) per a un disseny responsiu adaptat a ordinadors, tauletes i mòbils.
* **JavaScript (Vanilla ES6+)** per a la gestió de l'estat del qüestionari, el càlcul de resultats i la renderització dinàmica.
* **SVG** per als gràfics matemàtics i geomètrics nítids a qualsevol resolució.
